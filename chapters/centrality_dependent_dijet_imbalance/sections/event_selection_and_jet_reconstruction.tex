\subsubsection{Jet Calibration}
In Run 3, the in-situ and \ETA-intercalibration\footnote{In Run 3 the ATLAS JetEtMiss group stopped supporting the \texttt{EMTopoJets} so the cross calibration stretegy used in Run 2 was not an option. } calibrations were investigated in detail for \texttt{AntiKt4HIJets} for the first time using high-$\mu$ \pxp\ data at 13.6 TeV, leveraging the independence of the calibration on \SNN.
The \ETA-intercalibration is performed using the matrix-minimization method described in~\cite{BanerjeeAQP}, with the central reference method used as a cross check.
Calibration factors are derived in bins of \PT\ and \ETA\ and are applied as a correction to the jet \PT.
Cross-checks of the calibration have been established using dedicated MC samples at \SNN = 5.36 TeV and residual non-closure resulted in additional systematic uncertainty.
The work also included studies of the systematic uncertainty associated with each component of the calibration, as well as the jet energy resolution (JER).
